Reading the table:
1. **On non-violating cycles the tools agree on every fixture.** Clean-cycle differences from Icarus:
   - Yosys netlist: 0 in the 17 fixtures it can read;
   - model: 0 in the 11 fixtures it runs;
   - Verilator: only its 2-state initial value in the 2 memory fixtures.
2. On violating cycles there is a split, and it has the same shape for every qualifier and for `full_case` and
   `parallel_case`:
   - the netlist resolves the don't-care its own way: `y = d[s]` for a missing item, an OR for an overlap;
   - the event-driven simulator runs the source order and warns;
   - Verilator stops the run;
   - today's model silently follows the simulator, so a proof over `run2` would prove a value the scored netlist does
     not compute on those inputs.
3. `unique if` and `priority if` never reach scoring: the pinned frontend cannot read them.
4. `(* keep *)` and `(* no_rw_check *)` showed no functional split in these fixtures.

## Proposed `Admissible` clauses (each JUDGED, each from the evidence above)

| clause | text (draft) | evidence | status today |
|---|---|---|---|
| **A1** qualified case | A `unique`/`unique0`/`priority` `case` is admissible only with a proof that, on every settled state reachable under the task's rely, its claim holds: exactly one item matches (`unique`), at most one (`unique0`), at least one (`priority`). | Netlist and simulators split only on violating cycles: 7 of 7 qualified-case fixtures, 0 clean differences. Verilator aborts at a violation. `run2` silently takes the simulator's branch. | `srcgate` refuses the qualifiers (REFUSALS `later`, WP5); A1 is WP5's obligation, stated in `Admissible` instead of the loader |
| **A2** qualified if | `unique if`, `unique0 if` and `priority if` are not admissible. | The pinned Yosys frontend rejects them (syntax error); the model refuses them. Lift if the scored frontend reads them, then treat like A1. | refused by `srcgate`; class (e) of the audit |
| **A3** attributes | No attribute is admissible. A whitelist could later admit attributes measured functionally neutral (`keep`, `no_rw_check` here), on a separate check that they do not move the score. | `full_case` and `parallel_case` split netlist from simulation exactly as A1's qualifiers do, but with no simulator-side check at all. | `srcgate` refuses all attributes (`P-NO-TOOL-DIRECTIVES`) |
| **A4** self-read | An `always_comb` that reads, on some path, a bit it writes later on that path is not admissible. | 4 of 4 `rbw` rows: Icarus (and Xcelium, per the audit) stale, Yosys and Verilator settled. The LRM answer is deterministic and stale (9.2.2.2.1), so no run set lifts it. | loader refusal `AlwaysComb:self-read` (`gu-self-read`, `never`) |
| **A5** x as don't-care | No x/z digit in an expression other than a `casez`/`casex`/`inside` item pattern. | The netlist resolves the `'x` to a value the RTL shows as `x` (4 of 4 violating cycles). X9: this is also what makes generated designs (vexriscv, picorv32) undecidable by R-X. | `srcgate` refuses x/z digits |
| **A6** 2-state-complete case | A default-less `case` whose constant items cover every 2-state selector value is admissible, and its 4-state hold on an x selector is outside the statement's rely of known inputs. | Control fixture: the only difference is the x-selector cycle. X8: 15 such holds in cv32e40p. | today the loader and run2 accept it; the clause makes the reliance explicit |

**Not a clause.** Yosys and slang reading a case's context width or a parameter override differently is already refused by
