## (B) Decisions on a value that could be x (MEASURED counts; the "could be x" reading is stated per line)

| | references | records |
|---|---|---|
| designs with any procedural decision (`if`/`case` in a process) | **3 / 18**: `add_proc`, `add_proc_m` (`if (p[i])`), `sbox_table` (`case (x)` with `default`) | **0 / 4** |
| designs with the conditional operator `?:` only | 4 / 18: `add_mux`, `fdiv16` (35 sites), `fdiv16_gen` (12), `fdivp` (12) | 0 / 4 |
| decisions whose condition can be x **at the settled state** under the statement's hypotheses | **0** | **0** |
| decisions whose condition can be x **in some activation** from the x start under some legal schedule | 3 designs, one site each | 0 |

- *Settled* (READ + MEASURED): every procedural condition reads only input ports (`sbox_table`: `x`) or a signal another process drives
  (`add_proc*`: `p`, driven by `assign p[i] = a[i] ^ b[i]`). The statement's inputs are known (`HoldAll … ofBitVec`), and the tactic
  proofs state knownness of every driven signal (`sv_equations`' `known_*` facts), so no settled decision is on x.
- *Transient* (count MEASURED; reading JUDGED from LRM 9.2.2.2.1 and 4.7): an `always_comb` runs once at time zero and the Active-region
  order is arbitrary, so `add_proc*`'s `if (p[i])` can run before `assign p[i]`, see `p[i] = x` and take the else arm; it is re-triggered
  when `p[i]` changes. `sbox_table`'s `case (x)` can likewise see an undriven input if E lets the time-zero activation precede the
  environment's first input event.
- `?:` is not a decision: on an ambiguous condition LRM 11.4.11 merges the arms bit by bit, and `LVec.ternary` does the same
  (`LeanModels/Sv/Basic.lean:593`). Note that the *lowering* of `if` uses `Expr2.ifGuard c = ((|c) === 1'b1)` (`Comb2Proc.lean:298`), a
  known bit, so the lowered `?:` never merges: the lowered design reproduces `if`'s x-to-else rule through `===`, a non-monotone operator
  (input to X9).

## Verdict

1. **Transfer is one theorem per fragment, instantiated per record with the record's own certificate; no record needs re-proof.** Every
   accepted record and every reference proof exposes a named `Acyclic` theorem (by-hand proofs included), so the transfer of a record is
   `R-DESIGN2 (its CombDesign lemma) (its Acyclic lemma) solution`, mechanical per file.
2. **All 4 accepted records are inside E-core-0's assign-only fragment**, with the certificate on the loaded design. G-A's assign-only
   R-COMB plus an assign-only R-DESIGN2 transfers every record on the leaderboard today. G-B (one `always_comb`) is needed only for the 3
   `always_comb` references, plus the generic lowered-certificate lemma above.
3. **R-X's hypothesis must be read at the closed slot.** "The 4-state run makes no procedural decision on x" (ARCH-NOTE §4.3, R-X) is false
   for `add_proc`, `add_proc_m` and `sbox_table` if it ranges over every activation under the x start, though their settled decisions are
   all on known values. The census and the hypothesis should be stated on the closing activation of each process (or on the settled
   store), which is what X9's real-block census then measures.
