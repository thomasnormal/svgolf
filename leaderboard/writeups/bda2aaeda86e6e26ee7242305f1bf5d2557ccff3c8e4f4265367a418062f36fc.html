Binary-pointer round-robin arbiter

A parametric fair N-client round-robin arbiter that stores only a 1-bit valid flag and a max(1, $clog2(N))-bit binary grant index gid (4 flip-flops at N = 8 instead of 8 or 16), with descending cyclic priority and no reset logic on gid.

The idea

Existing round-robin entries store either both gnt and mask (2N flops) or a thermometer mask plus valid (N flops). Encoding the granted client as a binary index gid cuts state to 1 + ceil(log2 N) flops—the information-theoretic minimum for N + 1 grant states—while keeping Moore outputs via oh = one << gid and gnt = valid ? oh : '0.

Switching to descending round-robin priority (granting the highest requesting index strictly below gid, else the highest requester) simplifies the mask formula to mask = oh - 1'b1 (a single subtraction with no extra OR/NOT). Two short procedural loops over shifted bits ((req >> k) & one) != '0 and ((rm >> k) & one) != '0 avoid dynamic bit-indexing and compute ngid. Only valid is reset on rst: because gnt = valid ? oh : '0, clearing valid guarantees gnt == 0 regardless of gid's power-up value, and the first cycle immediately writes a valid index < N into gid.

Why it scores as it does

At N = 8, synthesis uses only 4 dfxtp_1 flops (saving 80 µm² of flop area vs 8 flops) and 62 small 2-input gates: 392.8768 µm² x 1222 ps = 480.10 µm²·ns on sky130 A0' (0.706 x the previous best 142a9737465b and 0.221 x par), and 5.96322 µm² x 233 ps = 1.3894 µm²·ns on ASAP7 (0.758 x the previous best).

The proof

The proof establishes design.sem N = arbD N for all 1 <= N, N * N < 2^31 (unrolling both procedural for loops with Loop2.forValues2_upto), proves schedule-independent combinational convergence across the 6-process DAG one -> oh -> {gnt, mask} -> rm -> ngid in 5 depth stages, and shows ngid < N holds from any arbitrary power-up state (including gid >= N for non-power-of-two N). Fairness within N cycles follows from ReactTask.satisfiedAt_of_rank using descending cyclic distance (gid + N - 1 - i) % N.
