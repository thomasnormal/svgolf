Direct-output insertion sorter at latency 2N - 1

A parametric N-element, W-bit streaming insertion-cell sorter that drops latency from 2N to 2N - 1 cycles by exposing cell 0 directly as Moore outputs, eliminates reset and zero-clearing on all N * W data flip-flops, and switches to unsigned >= comparisons.

The idea

The reference insertion-cell array (sorter_ins and record 3b1ec4b16d7a) registers out_valid <= tok[0] and out_data <= data[0 +: W] in an extra output stage, adding W + 1 flip-flops and 1 cycle of latency (2N = 16 at N = 8). Because tok[0] and data[0 +: W] are already flip-flop outputs, wiring assign out_valid = tok[0] and assign out_data = data[0 +: W] preserves the Moore output rule while removing 9 flops and reaching latency 2N - 1 = 15 (the Nth input is sampled on edge s + N and immediately appears on cell 0 at snapshot s + N).

Second, instead of resetting and zero-clearing all N * W data flops so that empty slots compare smaller than inputs, each cell guards its comparison with !tok[k] || (in_data >= data[k*W +: W]). Unoccupied slots (tok[k] = 0) unconditionally accept shifts/insertions regardless of power-up garbage, removing reset logic from all 64 data flops and restricting reset to the N token bits tok[k] <= (~rst) & tok[k+1].

Why it scores as it does

At (N, W) = (8, 8) on sky130 A0', the circuit uses 72 flops (down from 81) and 466 cells, measuring 4281.6064 µm² and 2076 ps over 15 cycles (31140 ps total) for 133329.22 µm²·ns (0.583 x par, 0.849 x 3b1ec4b16d7a). On ASAP7 it measures 68.23440 µm² x 15 x 372 ps = 380.7480 µm²·ns.

The proof

sv_mirror and sv_cycle (with pairwise write-window disjointness soG_disj) establish agreement with design.sem N W, one-pass settling of the two output wires, and the closed-form state step soG.next across the full range 1 <= N, 1 <= W, N * W < 2^31. The key invariant DataOK constrains only valid slots (N <= j + k < 2 * N) to (sortAsc ys).getD (j + k - N) 0, so uninitialized cells with tok[k] = 0 never enter the proof. getD_insertAsc relates the in_data >= data[k] cell updates to Tasks.Sorter.insertAsc, and StreamTask.PhaseModel with lat N W := 2 * N - 1 (including back-to-back starts at j = 2 * N - 1) closes Submission.solution.

What did not work

A log-depth binary-tree comparator per cell reached slightly lower score at (8, 8), but its [N-1:0][L:0][M:0] packed arrays overflowed 32-bit int width bounds at the extreme in-range corner (N, W) = (1, 2^30 + 1) and (2, 2^30 - 1), making the design unprovable over the full task range.
