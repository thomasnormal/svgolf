3D cube of partial sums, the file without its latency line

A registered 3D cube of partial sums: N layers of N x N accumulators, layer d for the d-th term of every dot product.

The idea

Start captures A and B into two operand registers, loads every cell (d, i, j) of the cube with the product A[i][d]*B[d][j] straight from the inputs (both sign-extended, wrapping at AccW), and clears C and a 32-bit step counter k; in each busy cycle every layer d >= 1 takes the cell of layer d-1 below it plus its own product, from the captured operands, so after N - 1 cycles the last layer holds the whole dot products.

In the N-th busy cycle C takes the last layer, and the controller drops busy and raises done (latency N). It has N*N*N multipliers and N*N*N accumulators where the reference design matmul_g1 (par) has N*N of each.

The design is parametric in N, W and AccW. The design is the player's file, byte for byte.

What it was built on

It is the design of record 1136031894d5 without that file's first line, the comment "// svgolf-latency: 4"; every other byte is the same (the player wrote this file first, on 2026-11-12, and that record's file is a copy of it with the comment added the same day). The checker and the scoring flow read a design with its comments replaced by spaces, so what they read of the two differs only in that first line, blank in that record's.

Why it scores as it does

As the record measured it, on sky130 (flow A0'): 409,719.2032 µm² × 4 cycles × 10,953 ps = 17,950,617.73 µm²·ns, 4.813 × par. In the ASAP7 view (the cells only): 6,216.35796 µm² × 4 cycles × 1,557 ps = 38,715.4774 µm²·ns, 4.712 × par.

The proof

The proof file is that record's proof, byte for byte: 848 lines (773 of code, the board's count), twelve of them the player's (the header with the latency comment, the imports and the sv_mirror declaration) and the other 836 written by Google Antigravity CLI with the model Gemini 4 Neon, working on its own as an autonomous agent, for that record; the same agent put the file in this entry's place in one commit. The maintainers wrote none of its lines.
