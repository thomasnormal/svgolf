# Weight-stationary array translated from Chisel

`ws_translated.sv` translates the weight-stationary systolic array of Gemmini, an open-source spatial-array generator from UC Berkeley, from its Chisel source into one parametric SystemVerilog module. The header keeps the generator's BSD-style licence notice, names the source commit and files, and lists every change; the translation is not endorsed by the generator's authors. The latency is 4N + 1, 17 cycles at N = 4.

## The idea

The source's structure is kept: an N × N mesh of 1 × 1 tiles, each processing element (PE) with two W-bit weight registers `c1` and `c2` whose roles alternate under a propagate bit, registers at each tile's input, skew lanes that delay row lane r of A and column lane c of the weights by r and c cycles, and a reverse skew that aligns the result rows. A transaction is two passes: a preload pass shifts B into the weight registers, last row first, then a compute pass streams the rows of A. A step counter replaces the original controller. It toggles the role bit `in_prop` before each pass and writes the result rows into `C`.

## Why it scores as it does

Keeping the structure costs area and cycles. With two weight registers per PE, a, b and d registers at every tile and three skew triangles, the netlist has 2,175 flip-flops and takes about 149,340 µm² on sky130. The period is 8,562 ps, but the two passes, the skews and the output register make 17 cycles: about 21.7 million µm²·ns, 5.83 × par on sky130 and 7.27 × par on ASAP7.

## The proof

The proof (2,463 code lines) follows the reference's steps. Its core is `Inv`, a structure with one field per register family, each pinning its windows to the steps at which they hold a definite value. For example, the `m_a` register of tile (r, c) holds A[u][r] at t = N + u + 2 + r + c, and row u of `C` is final from t = 3N + 2 + u. `inv_step` advances the invariant one busy step. `inv_start` establishes it from `in_prop` = 0; at t = 0 every claim about the array is vacuous, which is why the data registers can stay unreset. `fin_of_inv` and `C_product` read off the product at t = 4N + 1, and triangle-number lemmas (`tri_succ`, `tri_mono`) place the packed lanes.

## What did not work

The change list records two places where a literal translation failed svGolf's post-synthesis check. Registers that nothing read left undriven bits in the netlist, so the skew lanes are packed as triangles. Synthesis merged the per-column copies of valid and propagate, and the merged netlist read a vector from itself, so those bits are kept once per anti-diagonal.
