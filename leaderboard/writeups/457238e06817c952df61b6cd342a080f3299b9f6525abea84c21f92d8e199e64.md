# Processing in memory, sign-corrected multiply

`bank_mac.sv` models processing in memory, after the public description of a DRAM with an execution unit at each bank's edge: N banks, one multiply-accumulate unit each, and one sequencer issuing one command per cycle to all banks. The same machine is recorded as `bank_mac_mul.sv` with a plain signed multiplier. This version forms the signed product from an unsigned one and scores better.

## The idea

Bank r holds row r of A, sign-extended to AccW bits, in array row 0. The program is:

1. `ACT0` opens array row 0 into the row buffer.
2. For each column j of B, `FILL` broadcasts the column into every unit's register file and clears the accumulator. Then N `RD` commands each multiply-accumulate column 0 of the row buffer with entry 0 of the register file, and rotate both.
3. `LAST`, `ACT1`, `WR` and `PRE` move the collected results through the row buffer into array row 1, and `READ` copies that row to C and raises `done`.

The latency is N² + N + 6 cycles, 26 at N = 4, and there are only N multipliers.

The tweak: the unit reads the B entry as unsigned and subtracts the A entry, shifted left by W bits, when the B entry is negative. Modulo 2^AccW this is the signed product, and one multiplier operand has only W live bits instead of an AccW-bit sign extension.

## Why it scores as it does

On sky130 the design is 147,936 µm² with 2,658 flip-flops. Besides C it keeps four N²·AccW-bit arrays: two array rows, the row buffer and the result file. The period is 9,713 ps, so the time is 252,538 ps. The score is about 37.36 million µm²·ns: 10.017 × par on sky130 and 11.044 × par on ASAP7. Against the plain multiplier, the tweak saves 14,510 µm² and about 1 ns of period, which is 17% of the score. The serial schedule, with one multiplier per bank, still dominates.

## The proof

The proof has 1,736 code lines. After agreement (`mm_sem_eq`) and the clock step (`mm_cycle`), the program positions become predicates (`AtAct0`, `AtFill j`, `AtRd j k` to `AtRead`) that pin every register to a closed form. `BusyAt m` is their disjunction, with cycle counts. `busy_step` shows that each cycle reaches a later position or the finish, with one lemma per command.

The tweak costs about 70 lines over the plain version. `signExtend_neg_msb` says that a negative W-bit value, sign-extended, is its unsigned value minus 2^W. `mac_corr` uses it to show that the corrected unsigned product is the signed multiply-accumulate, and `mac_val` turns that into the partial sum `psum (k + 1)`.
