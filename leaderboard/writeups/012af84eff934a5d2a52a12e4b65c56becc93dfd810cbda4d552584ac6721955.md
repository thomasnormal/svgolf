# Weight-FIFO systolic array, uncleared PE registers

`ws_fifo_array.sv` is a weight-stationary systolic array. Its header says it is modelled on the published description of the TPU's matrix multiply unit (Jouppi et al., ISCA 2017). Weights come in through a FIFO and shadow registers, data enter as a diagonal wavefront, and each column ends in a rotating file of accumulators. The product takes 4N cycles, 16 at the scoring point.

## The idea

One step counter t drives the phases:

1. Weight load (t < N): the FIFO `wf` sends one row of B per step, last row first, into the shadow weights `wsh`, which shift down the array.
2. Swap (t = N): every PE copies its shadow weight into its active weight `wac`.
3. Wavefront (t ≥ N): the buffer `ub` sends one row of A per step into a triangle of data rows. Row k has k delay stages ahead of its N PE data registers, so array row k runs k steps behind row 0. Data move east and partial sums move south.
4. Accumulate: below column j, N accumulator words form a rotating file with one shared adder, active while 2N + 1 + j ≤ t ≤ 3N + j.

In this variant the start does not clear the PE registers. The swap writes the active weights before any data reach them, and each partial sum is rewritten from the top of its column before the accumulators read it. Data and active weights are stored already sign-extended to AccW bits.

## Why it scores as it does

The design takes about 107,010 µm² on sky130, with 1,650 flip-flops and an 8,229 ps period. Sixteen cycles give about 14.1 million µm²·ns, 3.78 × par (4.55 × par on ASAP7). Such an array is built for throughput, but the score counts the latency of one product: N of the 4N cycles load weights, and the last column's window closes only at step 4N − 1.

## The proof

The proof (2,381 code lines) has the reference's parts: agreement with a hand-built `tpD` (`tp_sem_eq`, with lemmas for the triangle offsets `base` and `DW`), the clock step `tp_cycle`, the registers through a cycle, then the phase model and the three rules. The counter, FIFO, buffer, data rows and accumulators get exact closed forms t steps after a start (`wfV`, `ubV`, `datV`, `cV`). The PE registers are not cleared, so their invariants say only which entries are known: `PEnt` pins a register family at the entries meeting a condition and allows anything elsewhere, and `shOK`, `waOK` and `psOK` are built on it. PE (k, j)'s partial sum, for example, is known from step N + 2 + k.
