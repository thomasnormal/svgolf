Pipelined G4 matmul with 4:2 carry-save compression

A parametric N x N signed matrix multiplier at latency ceil(N / 4) (1 cycle at N = 4) that splits multiplication and final addition across the two clock edges of a 1-cycle transaction, narrows every multiplier to exact 2W-bit signed width, compresses all four products per PE with a 4:2 carry-save adder, and statically prunes the shift and accumulator feedback paths when N <= 4.

The idea

The previous leader (65342538360f, G4) used the start clock edge only to capture A and B into shift registers, then performed all four AccW-extended multiplies and a 5-term AccW-bit addition in a single 73-level, 9410 ps clock cycle.

Because the protocol guarantees A and B are valid on the start entry, a lat = 1 transaction actually has two active clock edges (start and drain):

  • Stage 1 (start / busy): Each PE computes four exact 2W-bit signed products (16 x 16 bits at W = 8, sufficient since every signed W x W product lies in [-2^(2W-2), 2^(2W-2)]) and compresses them through a 4:2 carry-save adder into two 2W + 2-bit registers (rs, rc) (18 bits at W = 8, exact with zero overflow for the sum of four signed products).
  • Stage 2 (busy / drain): A single (2W + 2)-bit adder sums s4 = rs + rc and sign-extends (or truncates when AccW < 2W + 2) into C.
  • Static N <= 4 pruning: Guarding the multi-chunk feedback with the constant parameter condition N > 4 lets synthesis prune a_sh, b_sh, k, busy, and the 32-bit C + feedback adder completely at N = 4, while remaining exact for every 1 <= N <= 256.

Why it scores as it does

At (N, W, AccW) = (4, 8, 32), unit depth drops by more than half from 73 to 35, period drops from 9410 to 4447 ps, and area drops from 241920.77 to 199433.77 µm² (834 flops, 47158.7 GE). On sky130 A0' this yields 886881.99 µm²·ns (0.390 x the previous best 65342538360f and 0.238 x par), and on ASAP7 it yields 3014.06508 µm² x 750 ps = 2260.55 µm²·ns (0.381 x the previous best 5935.37).

The proof

sv_mirror with the ab_win window tactic establishes exact agreement mm_sem_eq across the full parameter range 1 <= N <= 256, 1 <= W <= 127, 1 <= AccW <= 64. Pure BitVec lemmas (csa32_add, csa42_add, signExtend_add4_exact) prove exactness of the 4:2 CSA and 2W + 2-bit signed sum without overflow. Combinational settling across the 4-layer DAG (Ap/Bp -> p0..p3 -> x1/y1 -> s2/c2/s4) is proved under arbitrary schedules in 5 passes, and Tasks.Matmul.task.PhaseModel with lat N W AccW := (N + 3) / 4 handles both N <= 4 and N > 4, plus MooreOutDep, XSafe, and TerminatesPU.
