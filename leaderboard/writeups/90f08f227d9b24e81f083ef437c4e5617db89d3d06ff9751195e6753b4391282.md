# Core mesh, column 0 fed at the start edge

`core_mesh.sv` computes the product on an N × N mesh of identical cores, modelled on the public description of a wafer-scale engine. Each core has a local memory holding a row of A, one multiply-accumulate unit and one input link from the north. Nothing inside the mesh is a controller: a core works when a valid message arrives. The same mesh is recorded as `core_mesh_late.sv`. This version feeds B one cycle earlier.

## The idea

- A message is {valid, last, payload}, and routers forward it one core south per cycle. Its arrival order stands for k.
- On a valid message, core (i, j) adds the head of its row times the payload to its accumulator and shifts the row.
- The edge streams column j of B into core (0, j), j cycles after column 0. In lockstep, the cores of a row would hold identical registers that synthesis would merge, so the skew keeps each core's memory its own.
- Column 0 has its own edge process, which takes its first message straight from the B port at the start edge and so saves the late variant's extra cycle.
- The far core raises `done` on its last message. The latency is 3N − 2, which is 10 at N = 4.

## Why it scores as it does

On sky130 the design is 108,006 µm² with 1,361 flip-flops, 1.24 times the reference's area. Each core does an AccW-bit multiply-accumulate per cycle, as the reference does, and the period is similar: 10,328 ps against 10,696 ps. Filling and draining the skewed mesh takes 3N − 2 cycles instead of N, so the time is 103,280 ps. The score is about 11.15 million µm²·ns: 2.991 × par on sky130 and 2.990 × par on ASAP7.

## The proof

The proof has 2,004 code lines. It starts with agreement (`c_sem_eq`) and the clock step (`c_profile`, `c_cycle`). The invariant `AtT` gives every register in closed form at time t. Core (i, j) has consumed `fc` = min(t − (i + j + 1), N) messages. The accumulators `accV` hold the partial dot products `psum` over those, the memories `amV` are shifted by the same count, and the links `lkV` carry the matching messages. `next_step` advances the invariant one cycle. `accV_fin` and `lkV_fin` show that at time 3N − 1 the accumulators hold the product and the links are empty. Time is counted as the snapshot index plus one, so the closed forms are those of the late variant. The column-0 process gets its own lemmas (`edge0_start`, `edge0_busy`, `bs_read0`).
