# Core mesh, every column fed one cycle late

`core_mesh_late.sv` computes the product on an N × N mesh of identical cores, modelled on the public description of a wafer-scale engine. Each core keeps a row of A in its own local memory and has one accumulator and one input link from the north. A core multiplies and accumulates when a valid message arrives. The same mesh is recorded as `core_mesh.sv`, which feeds B one cycle earlier. This version keeps the edge logic uniform and pays one cycle for it.

## The idea

- A message is {valid, last, payload}. Routers pass it one core south per cycle, and the arrival order stands for k.
- Core (i, j) adds the head of its local row times the payload to its accumulator and shifts the row.
- At the start edge the edge buffer takes B above N − 1 zero rows, and then it shifts down one row per cycle.
- One generate loop treats every column alike: column j enters core (0, j) j + 1 cycles after the start. The skew keeps each core's registers its own.
- The far core raises `done` on its last message. The latency is 3N − 1, which is 11 at N = 4.

## Why it scores as it does

On sky130 the design is 109,011 µm² with 1,393 flip-flops, slightly more than the early variant's 1,361. The period is 10,455 ps: one AccW-bit multiply-accumulate per core per cycle, as in the reference. Eleven cycles take 115,005 ps. The score is about 12.54 million µm²·ns: 3.361 × par on sky130 and 3.321 × par on ASAP7. That is 12% behind the early variant, almost all of it from the extra cycle.

## The proof

The proof has 1,728 code lines, about 280 fewer than the early variant's, because there is no column-0 special case. After agreement (`c_sem_eq`), the clock step (`c_profile`, `c_cycle`) and the commit (`commit_SS`) comes one invariant `AtT` that gives every register in closed form t cycles after a start. Core (i, j) has consumed min(t − (i + j + 1), N) messages (`fc`). The accumulators (`accV`) are the partial sums over those messages, the memories (`amV`) are shifted to match, and the links (`lw`, `lkV`) carry the right messages. `next_step` advances `AtT` one cycle. `accV_fin` and `lkV_fin` close the transaction after 3N − 1 cycles. The phase model's busy state with m cycles left is `AtT` at t = 3N − 2 − m.
