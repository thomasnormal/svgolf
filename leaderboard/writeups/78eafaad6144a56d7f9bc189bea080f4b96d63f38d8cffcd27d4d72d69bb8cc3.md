# 256-entry case table

This is par for the AES S-box, the simplest algorithm: the 256 entries of FIPS 197 Table 4 written as one `always_comb` block with a plain `case (x)` statement in `sbox_table.sv`. Every arm is `8'dK: y = 8'dS;`, and a `default: y = 8'd0;` arm closes it.

## The idea

There is no field arithmetic in the design at all. The whole S-box is left to synthesis, which turns the table into a gate network over the eight input bits. The `default` arm can never fire, since all 256 values are listed, but the design's header notes it is needed to avoid a latch. It must also be a known constant: the task's negative designs include the same correct table with an unreachable `x` default, which the source gate refuses (no `x` literal may appear, so synthesis never gets a value it is free to choose).

## Why it scores as it does

On sky130 the table synthesizes to 612 cells, dominated by `nand2` (264), `and2` (129), `or2` (70) and `mux2` (63), for about 3,446 µm². It was the fastest design on the board on 2026-11-13: unit depth 11, a critical path of 9 cells to `y[0]`, 2.29 ns. Its product, 7884.0 µm²·ns, defines par. The gate-level circuits on the board are 3.6 to 3.9 times smaller and 1.4 to 1.9 times slower, which is why every other record beats it. On the routed ASAP7 course the picture is the same: 51.96 µm² at 502 ps (the fastest there too), 26.09 µm²·ns.

## The proof

The proof is a single line:

```lean
theorem solution : Goal := by sv_exhaustive
```

under `set_option maxHeartbeats 1000000`, plus a `#guard_msgs` pin that the axioms are only `propext`, `Classical.choice` and `Quot.sound`. The library tactic reads the design through its lowering, compiles the `case` once into a word-level table lookup (one bitmap per output bit), and decides `y = sbox x` on all 256 inputs by kernel evaluation. The point worth noting is what it compares against: `sbox` in the task's trusted statement is defined algebraically (the inverse as `x^254` by repeated squaring, then the affine map with `0x63`), so the kernel check ties the transcribed table to the field definition, not the table to itself. The record lists a build time of about 35 s.
