# Strassen, one level, seven MAC engines

`strassen_one_level.sv` applies one level of Strassen's algorithm to 2 × 2 blocks of size H = ⌈N/2⌉. It computes seven block products instead of eight, each on an H × H array of multiply-accumulate cells: 28 multipliers at N = 4.

## The idea

- `start` captures A and B into shift registers that move one column of A and one row of B per step, so every select is static.
- Each step forms the ten pre-sums (S1 to S7, T1 to T7) for one column and one row, exact in W + 1 bits.
- Cell (u, v) of engine r adds S_r[u][w]·T_r[w][v], wrapping at AccW bits.
- At t = H + 1 the four post-sums, such as C11 = M1 + M4 − M5 + M7, write C once and raise `done`.
- For odd N the matrices are treated as padded to 2H. The padded index meets row N of B, which reads zero, and the padded output row and column are never written.

The latency is H + 2, which is 4 at N = 4.

## Why it scores as it does

On sky130 the design is 222,363 µm² with 1,942 flip-flops, 2.55 times the reference's area. Each cell still does a multiply and an accumulate in one cycle, so the period, 10,883 ps, is close to the reference's 10,696 ps. The H steps halve the accumulation, but the pre-sum and post-sum stages add two cycles back: four cycles, 43,532 ps. The score is about 9.68 million µm²·ns: 2.595 × par on sky130 and 2.537 × par on ASAP7. Strassen saves against eight block products, which would be 32 cells here. The reference uses 16 cells over four steps, so at this size the saving does not show.

## The proof

The proof has 2,073 code lines and uses only `simp`, `omega` and `decide`. Agreement (`st_sem_eq`) and the clock step (`st_profile`, `st_cycle`) follow the reference.

The arithmetic section is the interesting part. `id11`, `id12`, `id21` and `id22` are Strassen's identities for one contraction index over the integers, proved by distributing the products and calling `omega`. `post11` to `post22` lift them, by recursion on the step count, to the engines' running sums `msum`. `post_dot` shows that the post-sum for entry (i, j) is `Tasks.Matmul.dot`. It splits the 2H-term sum into halves (`sumTo_split`), and for odd N it drops the padded index because B's row N reads zero (`extractLsb'_past`). `pre_range` and `preI_toInt` keep the pre-sums exact. `next_busy`, `next_last` and `model` finish the proof.
