# `tests/mul/unproved/`: test material without a proof

Every design the site shows has a kernel-checked proof (decided 2026-11-12), so the designs here are on no page,
chart, table or data file of the site. They stay in the repository as test material: `tests/run.py` checks that the
generator's output is up to date (`layout`) and simulates each file at its own width (`validate`).

- `dadda_rc_<N>.sv`, `dadda_ks_<N>.sv` (N = 8, 16, 32): a Dadda tree with a ripple or a Kogge-Stone final adder,
  generated by `gen_dadda.py` for ONE width each. Every internal width and index is a literal of that N, so no
  proof of the task's statement (every N in range) can exist for these files. Their measured numbers are history in
  `tasks/mul/README.md` ("Scores"). `dadda_rc_16.sv.time` is the measured synthesis time of one of them.

The ripple-carry Dadda tree came back as a parametric design (one file for every N) with its proof on 2026-11-12:
`tests/mul/baselines/dadda_rc.sv` and its `.lean`, which build at N = 8 and 16 the cells of `dadda_rc_<N>.sv` here
(`tests/mul/baselines/README.md`, which also says why the Kogge-Stone one is not there yet and how another proved
design joins).
